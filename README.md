# Customer Churn Prediction Using Artificial Neural Networks

## 📌 Project Overview
Customer Churn Prediction is a machine learning project that predicts whether a customer is likely to leave a telecommunications service provider. The project uses an Artificial Neural Network (ANN) to identify potential churn customers based on their service usage, account details, and customer-related attributes.

The goal is to help businesses identify customers at risk of leaving and take proactive steps to improve customer retention.

## 🎯 Objectives
- Analyze customer data to identify churn patterns.
- Preprocess data for machine learning.
- Build an Artificial Neural Network (ANN) classification model.
- Evaluate model performance using appropriate metrics.
- Support data-driven customer retention strategies.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Machine Learning:** Artificial Neural Network (ANN)
- **Libraries:** Pandas, NumPy, Scikit-learn, TensorFlow/Keras *(include only those actually used)*
- **Visualization:** Matplotlib, Seaborn *(if used)*

## ⚙️ Project Workflow
1. **Data Collection:** Load the telecommunications customer dataset.
2. **Data Preprocessing:** Handle missing values, encode categorical variables, and scale numerical features as required.
3. **Exploratory Data Analysis:** Examine customer characteristics and churn patterns.
4. **Model Building:** Develop an ANN model for binary classification.
5. **Model Evaluation:** Assess predictions using suitable classification metrics.
6. **Prediction:** Predict whether a customer is likely to churn based on the model's input features.

## 📊 Results
The model achieved approximately **81% accuracy** during evaluation.

Accuracy alone does not fully measure churn prediction performance. Precision, recall, F1-score, and the confusion matrix can provide additional insight into how effectively the model identifies customers likely to churn.
